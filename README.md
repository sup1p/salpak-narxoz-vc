# Altyn — необанк для Digital Natives

Прототип самостоятельного мобильного необанка (хакатон BCC Future Talent, Crypto Neobank Case): золото от 1000 ₸, кешбэк в граммах, прозрачная цена, Академия.

> Все данные синтетические. Реальные деньги, персональные данные, ключи и seed-фразы не используются.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # тесты денежной логики
npm run check:copy # запрещённые слова в UI
npm run build
```

## Демо-сценарий (≈3 мин)

1. Онбординг → код `1111` → любой PIN → квиз о рисках → тестовый баланс.
2. Главная → «Следующий шаг» → покупка в режиме Пробы → «Повторить по-настоящему».
3. Покупка 10 000 ₸ → Рентген → «демо: ускорить таймер» → **ошибка «Цена обновилась»** → новая цена → Face ID.
4. Профиль → Кешбэк → «В золоте» + галочка → Главная → «Оплатить кофе» (анимация добычи).
5. Золото → хранитель, аудит, доля в слитке; продажа.
6. Академия → «Спред и комиссия» → квиз по своему чеку.
7. Профиль → Налоги, Позови подарком, Уровни → демо «Инвестор» → Партнёры МФЦА.

Демо-панель в Профиле: переключение статусов «Золотого дождя» и «Сбросить демо».
