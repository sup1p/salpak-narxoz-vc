# GRAM by BCC — необанк для Digital Natives

Прототип самостоятельного мобильного необанка (хакатон BCC Future Talent, Crypto Neobank Case): золото от 1000 ₸, кешбэк в граммах, прозрачная цена, Академия.

> Все данные синтетические. Реальные деньги, персональные данные, ключи и seed-фразы не используются.

## Демо онлайн

**https://gram-virid-eta.vercel.app** — продакшн на Vercel (проект `gram`). Открывается с телефона, вход: любой номер → код `1111` → любой PIN.

Повторный деплой: `npx vercel deploy --prod` (нужен `vercel login`).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # тесты денежной логики
npm run check:copy # запрещённые слова в UI
npm run build
```

## Демо-сценарий (≈3 мин)

Вкладки: **Главная · Платежи · Сервисы · Сообщения · Ещё**. Для показа ошибок включите **Ещё → Демо для защиты → Демо-режим**.

1. Вход: любой номер → код `1111` → любой PIN → главная (карта 50 000 ₸ + сбережения 13 000 ₸, золото 0 г) и **тур по интерфейсу**.
2. «Купить золото» → первая покупка в режиме Пробы → «Повторить по-настоящему» → **3 честных факта** → **Рентген цены** (сверх рынка ≈ 0,8%) → *демо: ускорить таймер* → **«Цена обновилась»** → Face ID.
3. Сервисы → «Кешбэк и Золотой дождь» → «В золоте» → Платежи → Мобильная связь 3 000 ₸ → кешбэк 1% золотом; «Мой кешбэк» — итоги и лимит.
4. «Оплатить по QR» → сканер → оплата.
5. Сообщения → темы (Платежи, Кешбэк, Золото…) → тап открывает детали операции.
6. Главная → «Перейти к золоту»: стадия, цена покупки, хранитель; продажа.
7. Сервисы → Обмен ₸ ↔ USDT → **тест на понимание рисков** → обмен; Партнёры МФЦА; Счета других банков; Позови подарком.
8. Ещё → Демо для защиты → **Метрики гипотезы**.
