# Altyn — необанк для Digital Natives

Прототип самостоятельного мобильного необанка (хакатон BCC Future Talent, Crypto Neobank Case): золото от 1000 ₸, кешбэк в граммах, прозрачная цена, Академия.

> Все данные синтетические. Реальные деньги, персональные данные, ключи и seed-фразы не используются.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # тесты денежной логики
npm run check:copy # запрещённые слова в UI
npm run build
```

## Демо-сценарий (≈3 мин)

1. Вход: любой номер → код `1111` → любой PIN → главная с тестовыми 50 000 ₸ и **тур по интерфейсу**.
2. «Купить» → первая покупка в режиме Пробы → «Повторить по-настоящему» → **3 честных факта** → Рентген → «демо: ускорить таймер» → **ошибка «Цена обновилась»** → Face ID.
3. Профиль → Кешбэк → «В золоте» + галочка → Главная → «Кофе» (анимация добычи).
4. Золото → средняя цена, хранитель, доля в слитке; продажа (предупреждение о статусе).
5. Академия → «Спред и комиссия» → квиз по своему чеку; 2 урока + покупка = уровень «Копилка».
6. Профиль → Позови подарком → «Демо: друг купил» (+0,05 г) → Налоги (CSV).
7. Уровни → «Демо: открыть Инвестор» → Партнёры МФЦА (подключить / отозвать) → Обмен ₸ ↔ USDT.
8. Профиль → **Метрики гипотезы**: воронка ТЗ и пилот против целей.

Демо-панель в Профиле: статусы «Золотого дождя», «Сбросить демо».
